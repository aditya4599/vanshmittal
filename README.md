# Vansh Mittal

Personal site for Recal Academy, built around Vansh Mittal’s latest résumé.

## Edit content

Copy lives in `src/data/site.ts`.

Add a LinkedIn URL to `contact.linkedin` before sharing if you want the nav and footer links live.

Research card `href` fields are empty until published URLs are available.

## Develop

```bash
npm run dev
```

## Build

```bash
npm run build
```
